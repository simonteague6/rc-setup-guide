# 0001: One page with OS sections

The Setup Guide uses one page with separate macOS and Windows installation sections, followed by one shared VS Code walkthrough. Windows needs WSL, Git in Ubuntu, and Microsoft's WSL extension; macOS uses Xcode Command Line Tools and VS Code. Duplicating the shared walkthrough would make it easier for the two paths to drift apart.

Members choose their OS from links at the top and scroll to the shared setup when their editor is ready. The first pull request has its own page because it is a separate exercise.
